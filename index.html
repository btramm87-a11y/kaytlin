01 / THE PROCESS

From source to
signal brief.

Each run follows a small, traceable path. The public page illustrates the process with sample data.

01

Check source & scope

Confirm the supplied source, topic, time window, and access limits. Ask when an essential detail is missing.

⌕
02

Capture the content

Transcribe or review the selected segment, keeping meaningful timestamps and noting unclear passages.

≋
03

Weigh evidence

Separate source facts from interpretation. Look for repeated themes, concrete examples, and counter-signals.

⌁
04

Draft for review

Prepare a concise report with evidence, timestamps, confidence, and open questions before anything is saved.

↗

02 / QUALITY & BOUNDARIES

Useful, because
it shows its work.

A

Evidence first

Connect each trend observation to a timestamp, quotation, or example from the supplied source.

B

One source at a time

Describe patterns in the material provided. Do not present one source as proof of a global trend.

C

Mark uncertainty

Flag low audio quality, unclear wording, missing context, and conclusions that need checking.

D

Review before saving

Return the draft for the user to check. Save or share it only when the user asks and access is available.
