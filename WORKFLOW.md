# trieuvy23 vs stella — Standard Task Workflow

Closed loop: **Receive → Understand → Validate → Process → Check boundaries → Output / Handoff → Close**

## Step 1 — Receive task input

Capture the source, task label or ID if provided, context, original request, and parameters. If an essential detail is missing, pause and ask rather than guessing.

## Step 2 — Understand and classify

Confirm the request concerns analysis of the supplied audio or video and identify the topic, segment, language, and requested output. Hand off requests outside the Agent's scope.

## Step 3 — Validate information and access

Check that the source is readable and that access is authorized. Gather only the information and tool results needed for this run. Mark uncertain or unavailable material.

## Step 4 — Process the source

Transcribe or review the selected material, preserve useful timestamps, identify repeated themes and examples, and separate source evidence from interpretation.

## Step 5 — Check boundaries and risks

- **A — Complete and in scope:** continue to the report.
- **B — Missing or unclear input:** list the missing details and ask the user.
- **C — Outside scope or access:** explain the limit and hand off.
- **D — Risk or conflicting evidence:** flag the issue, avoid unsupported decisions, and escalate for review.

## Step 6 — Return a standardized result

Include the source and scope, summary, evidence with timestamps, interpretation, confidence, uncertainty, and suggested next action. Use a task ID only if the user supplied one.

## Step 7 — Close the task

Return the draft for user review. Create or share a document only when requested and authorized. Report completion only after verifying the result.
