# trieuvy23 vs stella — Usage Guide

## Public showcase

1. Open the trieuvy23 vs stella page.
2. Review the four-step process and the quality standards.
3. Select **Reveal sample report** to see fixed illustrative content.
4. Treat the sample as a layout demonstration, not as a real analysis.

## Proposed Agent workflow

1. Supply one audio/video source or an authorized URL.
2. Add the topic, time range, and preferred report language if needed.
3. Review the Agent's source and access confirmation.
4. Check evidence, timestamps, uncertainty, and the proposed summary.
5. Ask for corrections before requesting a saved or shared report.

## Current limits

The published showcase is static. It cannot fetch URLs, receive files, transcribe media, call an AI service, or create Feishu documents. A connected Agent and authorized tools are required for those actions.
